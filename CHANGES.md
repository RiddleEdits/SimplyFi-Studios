# Kyro Media UI repair

- Removed the fixed cyan playhead line and diamond from the hero's Three.js composition.
- Shifted and scaled the hero timeline to keep it from running through the headline and supporting copy.
- Reworked shared glass surfaces and buttons to use white, navy, and blue rather than the old dark theme.
- Improved contrast and visibility in the stats thumbnail wall and CTA floating thumbnails.
- Converted the homepage Tech and Minecraft showcase cards to light surfaces with readable metadata.
- Removed both individual “View case study” buttons; retained the single “View all case studies” button.
- Updated FAQ active states, navigation capsule, CTA card, and footer to fit the blue theme.
- Kept the existing links, video data, FAQ switching, and booking flow intact.
